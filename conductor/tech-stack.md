# Technology Stack: GlassPiano

## Frontend
- **Framework:** React (v19)
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** TailwindCSS

## Backend
- **Framework:** Express
- **Environment:** Node.js

## Storage
- **Database Wrapper:** Dexie.js (IndexedDB for client-side storage)

## Specialized Libraries
- **Computer Vision:** MediaPipe Hands
- **Sheet Music Rendering:** OpenSheetMusicDisplay
- **Audio/MIDI Processing:** Tone.js, WebMidi
- **Animations:** Canvas Confetti
