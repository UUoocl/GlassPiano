# Product Guide: GlassPiano

## 1. Core Value Proposition
GlassPiano is an **AR Companion** designed to overlay feedback and guidance on real physical keyboards, enhancing the piano learning experience through computer vision and interactive digital sheet music.

## 2. Target Audience
- **Beginners:** Users learning piano basics who need intuitive, visual feedback.
- **Music Educators:** Teachers using the application as a tool to monitor and improve student progress.

## 3. Feature Focus
To deliver on our core value, development will prioritize:
- **Hand Tracking:** High-precision, low-latency gesture and finger recognition using MediaPipe.
- **Sheet Music Integration:** Enhancing digital rendering and interaction via OpenSheetMusicDisplay to sync seamlessly with user performance.
- **Viewport Optimization:** A fit-to-frame layout that adapts to any screen size without vertical window scrolling.
- **Auto-Scrolling:** Smooth, automatic vertical scrolling to keep the active staff aligned to the top.
- **Sequential Onboarding:** A guided calibration wizard to ensure correct MIDI, layout, and visual setup.

## 4. Success Metrics
The primary metric for success is **Performance**. The application must maintain low latency in hand tracking, sheet music rendering, and audio/MIDI playback to ensure a realistic and responsive AR experience.
